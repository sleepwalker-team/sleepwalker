# High-level changes
- Added new breathing experiments via `train_breathing.py`, plus new `breathing.hml` and `sleep.hml` experiment configs.
- Refactored `train_sleep.py` into a cleaner multi-dataset training entrypoint with explicit train/val/test split handling, MLflow logging, and simpler experiment configuration.
- Improved dataset sampling so filtered patients can keep multiple disjoint valid regions instead of forcing one continuous retained window.
- Cleaned up shared trainer utilities and moved dataset-combination logic into the dataset layer.
- Improved the multiclass results TUI with better path resolution for artifacts, scrollable confusion matrices, and a truecolor fix for tmux/SSH terminals.
- Removed older task scripts that were superseded by the new setup: `train_body_position.py`, `train_lm.py`, `train_noisy.py`, and `sleepwalker/trainer/NegativeGroupedChanelMulticlassTrainer.py`.

API changes
- `BaseModel` now requires `input_spec() -> (shape, meta)`.
  This is the main model-facing API change. All concrete models were updated to implement it, and `Run.run()` now uses `model.input_spec()` instead of inferring input size from the dataset.
- `combine_datasets` moved.
  Import it from `sleepwalker.datasets.MultiDataset` now. The old path via `sleepwalker.trainer.utils.splits` was removed along with `splits.py`.
- `trim_wake(...)` was replaced by `trim_event(...)`.
  The new helper is more general: it trims to the first/last occurrence of selected events instead of being wake-specific.
- `BaseDataset` semantics changed for filtered label regions.
  After `prepare_patient`, the dataset now supports sparse/disjoint valid window offsets through internal `start_offsets`, so sampling respects multiple retained segments rather than sampling gaps between them.

Notable behavioral changes
- Rare-event training windows are sampled more accurately after the BaseDataset indexing fix.
- Sleep training no longer relies on the older shared sleep-time filtering helpers; that logic now lives directly inside `train_sleep.py`.
- Sleep staging and breathing scripts now make heavier use of explicit dataset construction and per-task trimming/target preparation.

Scripts to inspect for usage examples
- `train_breathing.py`
  Best entrypoint for the new breathing task, event trimming, target construction, and Ruhrland-specific channel handling.
- `train_sleep.py`
  Best example of the current multi-dataset training flow, patient filtering, split construction, MLflow logging, and `RunCfg` usage.
- `train_arousal.py`
  Good minimal example of the newer `trim_event(...)` flow on an existing task.
- `train_desaturation.py`
  Useful companion example for another event-detection training setup using the current training stack.
- `bin/explore_multiclass.py`
  Inspect this for the updated results TUI, MLflow artifact lookup, confusion-matrix rendering, and terminal color/debug handling.

If users are extending models, they should inspect `sleepwalker/models/Basemodel.py` first because the new `input_spec()` requirement is the main breaking interface change in this batch.
