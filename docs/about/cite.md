# Cite us

!!! warning "Citation placeholder"
    A formal publication for Sleepwalker is in preparation. Until then, please cite the software by its repository and version. Replace the block below with the published reference once it is available.

If you use Sleepwalker in academic work, please cite the software and, where relevant, the underlying datasets and the original model papers.

## Software

```bibtex
@software{sleepwalker2026,
  title  = {Sleepwalker: Train, package, and run sleep models on EDF recordings},
  author = {{Sleepwalker Contributors}},
  year   = {2026},
  url    = {https://github.com/sleepwalker-team/sleepwalker},
  note   = {Release v<version>}
}
```

## Datasets

Cite the specific sleep datasets you trained on or evaluated against (for example Sleep-EDFx, SHHS, or ISRUC) according to their own citation requirements. See the [dataset reference](../reference/datasets.md) for the datasets Sleepwalker ships adapters for.

## Models

When you train or run a specific architecture (for example AttnSleep), cite the original paper that introduced that model in addition to the Sleepwalker software reference.
