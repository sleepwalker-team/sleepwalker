# Research Sleepwalker support in Aeon

Status: Backlog research idea.

## Goal

Assess how to use Sleepwalker models inside [Aeon](https://www.aeon-toolkit.org/en/stable/).

## Research tasks

- Inspect Aeon's classifier interface, dependency rules, and contribution requirements.
- Identify suitable Sleepwalker models and the adapter work they need.
- Assess data shapes, training configuration, class probabilities, and supported target types.
- Identify changes needed in each project. Plan an upstream pull request in the Aeon repository if the approach is feasible.

## Completion criteria

- Record a short feasibility assessment, limitations, and proposed model scope.
- Define the next work item for an Aeon contribution if the assessment supports it.

## Input needed

Select model candidates when this research starts.

The current integration work is [Aeon inside Sleepwalker](aeon-support.md).
