Bedienung

Im Signalplot ziehen, um ein Intervall zu markieren. Über „Verschieben“ die Zeitachse bewegen; mit dem Mausrad zoomen.

Unter den Signalen eine Vorhersagespur anklicken, um Zeit und Aufgabe auszuwählen. Ziehen in einer Spur markiert ein Intervall. Rechtsklick auf die Auswahl öffnet das Menü zum Korrigieren oder Löschen eigener Änderungen. Ein Klick auf einen Klassenabschnitt rahmt diesen ein.
